# erster-pr

Ein Übungsprojekt, um den Ablauf eines Pull Requests auf GitHub kennenzulernen.

## So funktioniert ein Pull Request

1. Einen neuen Zweig (Branch) vom Hauptzweig `main` abzweigen.
2. Auf diesem Zweig eine Änderung machen und committen.
3. Den Zweig zu GitHub hochladen (pushen).
4. Auf GitHub einen Pull Request öffnen, der die Änderung zum Zusammenführen vorschlägt.
5. Die Änderung prüfen und den Pull Request mit **Merge** in `main` übernehmen.
