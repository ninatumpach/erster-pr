Ein Übungsprojekt, um den Ablauf eines Pull Requests auf GitHub kennenzulernen.

## Taschenkalender

`index.html` ist eine kleine Kalender-App ohne Abhängigkeiten. Einfach im Browser öffnen.

- Monatsansicht mit Kalenderwochen (KW), Montag als Wochenbeginn
- Schweizer Feiertage (inkl. Ostern, Auffahrt, Pfingsten, berechnet pro Jahr)
- Termine anlegen, bearbeiten und löschen, mit Uhrzeit oder ganztägig und Kategorie
- Speicherung im `localStorage` des Browsers
