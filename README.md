# erster-pr

Ein Übungsprojekt, um den Ablauf eines Pull Requests auf GitHub kennenzulernen.

## Haushaltsbuch

`haushaltsbuch.html` ist eine kleine Finanz-App ohne Abhängigkeiten. Einfach im Browser öffnen.

- **Budget:** Einnahmen und Ausgaben pro Monat, Auswertung nach Kategorie
- **Abos:** Kosten pro Monat und Jahr, nächste Kündigungsfrist pro Abo
- **Krankenkasse:** Jahreskosten je Franchise (Prämien, Franchise, Selbstbehalt) und die günstigste Wahl für die erwarteten Arztkosten
- Speicherung im `localStorage` des Browsers
